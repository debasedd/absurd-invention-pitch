# One-Sentence Absurd Invention Pitch

[![One-Sentence Absurd Invention Pitch](https://make.fun/badge/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a.svg)](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a)

A tiny program for the [One-Sentence Absurd Invention Pitch](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty on [make.fun](https://make.fun).

It writes one sentence to `/output/entry.txt` — a ridiculous invention
pitch for a tiny everyday annoyance:

> A houseplant that texts your boss 'he forgot to water me again' every time you skip a day, so your neglect finally has a witness with a deadline.

Run it with:

```sh
python3 main.py
```
